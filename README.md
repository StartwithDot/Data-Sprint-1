# Data Sprint 1

Welcome to the Data Sprint 1 repository. This project builds a complete data platform using a Kimball star schema and a Medallion pipeline (bronze, silver, gold). 

## Structure

* **`students/`**: Contains individual practice folders for all cohort members.
* **`platform/`**: The shared data pipeline code, built collaboratively.
* **`delivery/`**: The shared delivery outputs like dashboards and presentations.
* **`docs/`**: Important project documentation. Please read the `student-guide.md` to get started.

Please see the `CONTRIBUTING.md` file for rules on how to add your work to this repository.
