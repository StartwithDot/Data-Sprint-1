# Data Sprint 1

Welcome to the Data Sprint 1 repository. This project builds a complete data platform for analyzing the MCA (Ministry of Corporate Affairs) registry data, incorporating insolvency data (IBBI), economic context (RBI), and state-level statistics (CDM) to support client due diligence and risk assessment. The platform uses a Kimball star schema and a Medallion pipeline (bronze, silver, gold).

## Structure

* **`students/`**: Contains individual practice folders for all cohort members. Each student works within their specific `students/DEx/weekY/` folder to complete daily tasks.
* **`platform/`**: The shared data pipeline code, built collaboratively by the weekly rotation group.
* **`delivery/`**: The shared delivery outputs like dashboards and presentations, built collaboratively by the weekly rotation group.
* **`docs/`**: Important project documentation, including the project brief, task list, and student guide. Please read the `student-guide.md` to get started.

Please see the `CONTRIBUTING.md` file for rules on how to add your work to this repository.
