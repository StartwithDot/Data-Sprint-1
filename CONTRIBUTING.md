# Contributing to Data Sprint 1

Thank you for contributing to the Data Sprint 1 project. 

## General Rules

1. **One Task, One Commit:** Only commit files related to a single task at a time.
2. **Work in Your Folder:** Unless you are on the platform rotation team, only commit files inside your assigned `students/DEx/` folder.
3. **Pull Requests:** All changes must be made through pull requests. Direct pushes to the `main` branch are disabled.
4. **Merge Strategy:** When merging, always use a regular merge commit or rebase merge. Do not use squash and merge. This preserves everyone's individual contribution history.

For a full breakdown of the daily workflow, please read the `docs/student-guide.md` file.
